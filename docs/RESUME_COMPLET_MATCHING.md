→ Dessine : deux boules proches dans l'espace (384D c'est juste beaucoup dimensions)

→ Crée mnémonique ou acronyme
→ "0.85 = B for BERT, 0.85 is strong correlation"
→ "-8.5% = un 8 et un 5, voilà"
→ "1.5s = une seconde et demie, simple"
→ Écris plusieurs fois

→ Dis les 3 phrases de secours (voir CHEAT_SHEET)
→ "On a 3 moteurs... heuristique, ML, BERT... corrélation 0.85..."
→ Expert comprendra que tu connais basics même sous stress

→ Pause 2-3 secondes (pas grave)
→ Dis ce que tu penses logiquement
→ Si pas sûr : "Je pense X, mais je peux vérifier"
→ Honnêteté > BS (expert respecte)
