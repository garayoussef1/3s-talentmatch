1. DESCRIPTION DU PROJET
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3S TalentMatch est une plateforme web intelligente de matching CV / offres d'emploi.
Elle permet a des candidats d'uploader leurs CVs, qui sont automatiquement analyses
par un pipeline NLP, puis mis en relation avec des offres d'emploi par des recruteurs.

ETAT ACTUEL : Sprint 2 termine (NLP complet), Sprint 3 en cours (matching).

5. BASE DE DONNEES — TABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TABLE users
  id UUID PK | nom | prenom | email (unique) | hashed_password
  role : candidat / recruteur / admin
  is_email_verified | verification_code | verification_code_expires
  reset_code | reset_code_expires
  auth_provider : local / google / linkedin
  oauth_id | avatar_url | created_at | updated_at

TABLE candidates
  id UUID PK | cv_id (unique) | filename
  user_id FK->users (candidat qui a uploade)
  candidature_status : en_attente / accepte / refuse
  nom | email | telephone | linkedin | github
  parsed_data (JSON complet du pipeline NLP)
  raw_text (texte brut extrait) | extraction_method
  created_at | updated_at

TABLE cv_documents
  Lie a un candidat -> stocke les fichiers CV

TABLE job_offers
  Offres d'emploi creees par recruteurs
  titre | description | competences requises | statut

TABLE matches
  Candidat <-> Offre | score de matching | statut

6. ROLES ET ACCES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CANDIDAT
  - Peut s'inscrire lui-meme via /register
  - Upload son propre CV
  - Voit ses candidatures + statut (en_attente / accepte / refuse)
  - Voit les offres disponibles

RECRUTEUR
  - Cree par un admin (ne peut pas s'inscrire tout seul)
  - Voit tous les candidats + leurs donnees NLP
  - Change le statut des candidatures
  - Cree/gere les offres d'emploi

ADMIN
  - Acces complet (gestion users, candidats, offres)
  - Peut supprimer tous les candidats
  - Peut creer des comptes recruteurs

7. PIPELINE NLP — FONCTIONNEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Quand un CV est uploade -> le fichier passe par ce pipeline :

ETAPE 1 — EXTRACTION TEXTE (services/extraction/)
  PDF texte    -> PyMuPDF (detection colonnes) + pypdf fallback
  PDF scanne   -> EasyOCR (detection auto si texte < 100 caracteres)
  DOCX         -> python-docx
  PNG/JPG      -> EasyOCR direct

ETAPE 2 — PIPELINE NLP (services/nlp/nlp_parser.py)
  1. ContactExtractor     -> email (regex), telephone (regex filtre), LinkedIn, GitHub
  2. EntityExtractor      -> nom/prenom (5 passes : prefixe "Nom:", honorifiques,
                            CamelCase split, spaCy NER PERSON, 1ere ligne)
  3. SkillsExtractor      -> 300+ competences (23 categories) + NER dynamique spaCy
  4. FormationExtractor   -> diplomes, ecoles, annees, en_cours (comparaison date courante)
  5. ExperienceExtractor  -> postes, entreprises, dates debut/fin, missions
  6. SectorClassifier     -> classification parmi 15 secteurs (IT, Finance, BTP, etc.)
  7. HFCamembertNameExtractor -> DESACTIVE (HF_ENABLE_CAMEMBERT_NAME=0 dans .env)

8. AUTHENTIFICATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- JWT (python-jose) : token Bearer dans Authorization header
- Duree : 1440 min (24h), configurable via ACCESS_TOKEN_EXPIRE_MINUTES dans .env
- Mot de passe : bcrypt (passlib)
- Verification email : code 6 chiffres envoye par email (mode log en dev)
- Reset mot de passe : code 6 chiffres par email
- OAuth Google  : /api/auth/oauth/google (requiert GOOGLE_CLIENT_ID dans .env)
- OAuth LinkedIn: /api/auth/oauth/linkedin (requiert LINKEDIN_CLIENT_ID dans .env)

Email en dev : EMAIL_MODE=log
  -> Le code de verification est ecrit dans logs/backend.out.log
  -> Pas besoin de vrai compte Gmail en developpement

  ..\.venv-10\Scripts\python.exe -m alembic downgrade -1
    - Annule la derniere migration (revenir en arriere d'une etape)

  ..\.venv-10\Scripts\python.exe -m alembic current
    - Affiche la version de migration actuelle de la base
